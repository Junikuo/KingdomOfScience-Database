# KingdomOfScience-Database
 Kingdom of Science Database

Kingdom of Science Database is a simple console application inspired by the anime Dr. Stone. It was developed using Python and SQLite to practice relational database design, SQL queries, and Python database integration.

 Objective:

The goal of this project was to strengthen my SQL and Python skills by building a relational database from scratch, creating an interactive menu, and managing the project using Git and GitHub.

Technologies Used:

Python
SQLite
sqlite3
Git
GitHub

Database Structure:

The database consists of four related tables:

Characters – Stores information about the characters.
Inventions – Stores the inventions created in the series.
Materials – Contains the materials used to build inventions.
Character_Inventions – Links characters with their inventions and records each character's contribution.

How to Run:

Clone the repository.
Open the project in Visual Studio Code.
Make sure Python 3 is installed.
Run main.py.

Through this project I practiced:

Creating relational databases with SQLite.
Writing SQL queries (SELECT, INSERT, and JOIN).
Connecting Python to SQLite using the sqlite3 module.
Building an interactive console menu.
Using Git and GitHub for version control and project recovery.
